## 1. 摸底：现在到底有什么

右键基础设施已经统一：4 个菜单全部用**同一个 `ContextMenu` 组件**（portal + 贴边翻转 +
Esc/点外关闭，`ui/ContextMenu.tsx`），没有第二套实现。分发点：

| 场景 | 位置 | 现有项 |
|---|---|---|
| 片段（canvas hit-test） | `TimelineView.onContextMenu` | 分离音频 / 导出这段的音频 / 配一段音频 / 定格 / 倒放 / 向右旋转90° / 水平翻转 / 删除音频 / 静音 / 复制 / 删除片段（13 项） |
| 时间线空白 | 同上分支 | 粘贴到此处 / 在此处插入音频…（2 项） |
| 轨道头 | `openTrackMenu`（⋮ 溢出按钮共用） | 重命名 / 独奏 / 静音(视/字) / 复制轨道 / 上移 / 下移 / 添加视频·音频·字幕轨 / 删除轨道 —— **已完整，不动** |
| 素材卡 | `AssetPanel` | 重新链接(仅离线) / 添加到时间线 / 删除素材 —— **已完整，不动** |

### 1.1 三个真实缺陷（本方案要修的）

1. **右键会重置多选**：`onContextMenu` 命中片段后无条件 `setSelectedClipId(clip.id)`——
   用户 Ctrl 加选了 3 段再右键，多选被清空，随后菜单里「删除片段」**只删右键那一段**
   （菜单直接 dispatch `removeClip`，绕过了键盘 Delete 用的 `removeSelectedClip` 批量路径）。
   菜单与键盘行为不一致 + 多选丢失，两个问题同一根源。剪映/PR 右键都**保持多选**。
2. **菜单不分片段类型**：文字片段的菜单里有 分离音频/定格/倒放/删除音频/静音/导出音频 6 条
   无关项（文字没有音频、定格倒放是画面帧语义）；音频片段的菜单里有 旋转/翻转/定格/倒放/
   分离音频 等画面操作。与刚做完的"属性栏按类型动态分组"是同一条经验：**无关项不渲染**。
3. **键盘独占的高频操作没有右键入口**：分割（B）和波纹删除（Shift+Delete）只存在于快捷键
   ——右键是新手发现功能的第一个地方（`docs/nle-baseline.md`：剪映/PR 的分割/倒放/定格都有右键项）。

### 1.2 可直接复用的现有能力（不新写逻辑）

| 菜单项 | 复用 |
|---|---|
| 删除（批量） | `keymap.removeSelectedClip`（多选合成一个撤销步） |
| 波纹删除 | `keymap.rippleDeleteSelectedClip`（同上） |
| 分割 | `keymap.splitAtPlayhead`（TopBar 分割按钮同款） |
| 复制（批量） | `clipboard.copyClips(doc, selection)`（本就接受数组） |
| 新建文字（空白处） | `ensureTextTrackOps` + `addClip`（TextPanel.createText 同一条路，抽成共享函数避免第二份实现） |

## 2. 方案

### 2.1 片段右键（改造）

**选择语义**：右键命中的片段**已在多选集合里 → 保持多选**；不在 → 单选它（剪映/PR 同款）。
菜单项作用于整个选中集合。

**按类型裁剪**（判据与属性栏同一套：`clip.text` → 文字；`role==='audio'` 或素材 kind==='audio' → 音频；否则视频/图片）：

| 分组 | 视频/图片 | 音频 | 文字 |
|---|---|---|---|
| 音频类 | 分离音频 / 导出这段的音频 / 配一段音频 / 删除音频 / 静音 | 静音 / 导出这段的音频 | **不渲染** |
| 画面帧类 | 定格 / 倒放 | **不渲染** | **不渲染** |
| 变换类 | 向右旋转90° / 水平翻转 | **不渲染**（无画面） | 保留（文字有 transform） |
| 编辑类 | 分割 / 复制 / 波纹删除 / 删除片段（三类型都有） | 同左 | 同左 |

编辑类细节：
- 「分割」= 在播放头处切（`splitAtPlayhead`），播放头不在片段内时置灰并写原因（同定格的文案套路）
- 「波纹删除」「删除片段」用 selection 批量版；多选时文案带数量（`删除 3 个片段`）
- 顺序对齐剪映：分割/定格/倒放/复制 在前，删除类在最后（danger 红色）

### 2.2 空白右键（补充）

- 粘贴到此处（已有）、在此处插入音频…（已有）
- **新增「在此处新建文字」**：落文字轨播放帧处（把 `TextPanel.createText` 的建轨+落片抽成
  共享函数，两个入口共用；默认文案与默认时长走同一份 `readPrefs().defaultClipSeconds`）

### 2.3 轨道 / 素材菜单

**不动**（摸底确认已完整）。

### 2.4 明确不做

- 撤销/重做进菜单（TopBar + 快捷键已覆盖，菜单保持操作聚焦）
- 替换素材 / 画面裁切（Crop）/ 变速预设（能力不存在或属属性栏，`nle-baseline` 未要求右键）
- 子菜单（二级菜单）——`ContextMenu` 组件是平铺列表，引入子菜单是组件改造，收益低

## 4. 测试设计（`verify-context-menu.mjs`，≥10 断言）

1. 右键视频片段 → 菜单项集合正确（含 分割/波纹删除，顺序正确）
2. 右键文字片段 → 无 分离音频/定格/倒放/静音（无关项不进 DOM）
3. 右键音频片段 → 无 旋转/翻转/定格/倒放/分离音频
4. **多选保持**：Ctrl 加选 2 段 → 右键其中一段 → selection 仍是 2 个，菜单「删除」文案带数量
5. 批量删除：多选右键删除 → 一次撤销步恢复 2 段
6. 波纹删除菜单项：删除后同轨后续片段左移
7. 分割：播放头压在片段中间时可用，点击后片段一分为二；播放头在片段外置灰
8. 空白右键 → 「在此处新建文字」→ 文字轨出现片段且被选中
9. 空白右键 → 粘贴到此处（复制后）仍工作（回归）
10. 轨道/素材菜单回归（既有 `verify-audio-menu`/left-tabs 覆盖）
