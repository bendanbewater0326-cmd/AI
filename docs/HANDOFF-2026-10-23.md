## 一、项目是什么（30 秒理解）

**veditor**：可嵌入 AI 客户端的极简视频剪辑器。
- 纯前端：WebCodecs + WebGL2 + IndexedDB，**无后端**
- React 19 + TypeScript + **esbuild 自写构建**（**不用 Vite/Webpack/MUI/Tailwind，项目定案，别引入**）
- 依赖极少：`react` / `react-dom` / `mp4-muxer` / `gifenc`
- AI 隐形化：默认零 AI 痕迹，`Ctrl/Cmd+K` 唤起命令栏，`Esc` 消失

**目录**：
```
src/core/      纯逻辑（timebase 时基、types、store、operations、captions、adjust、prefs…）
src/render/    WebGL2/Canvas2D 渲染（着色器、曲线、LUT、蒙版）—— 底层，尽量别碰
src/media/     解码器池、播放引擎、代理媒体、降噪、静音检测
src/ui/        所有 React 组件（App、各面板、TimelineView…）
src/persist/   IndexedDB 封装、自动保存、预设、工程文件
src/host/      宿主集成（web component <veditor-panel>、postMessage 命令通道）
tests/         verify-*.mjs（无头 E2E）+ *.test.mjs（Node 单测）
docs/          PRD、架构、各面板方案、PROJECT-STATUS（全史）
```

**铁律**：**同一条规则只能有一个定义点**。90% 的隐蔽 bug 来自"两处写了同一规则"。

## 四、关键约定（新 AI 必读，违反必出 bug）

### 技术硬约束

1. **时基守卫**：`npm run check` 会扫描"与 fps/frame/时间标识符同现的 1000 缩放"。
   帧↔毫秒/秒**必须走 `core/timebase.ts`**（`frameToMs` / `msToFrame` / `secondsToFrames`…）。
   **别自己写 `* 1000`**。
2. **零底层改动**（各面板的硬边界）：不动 `src/render/**`、`src/export/**`、
   `src/media/playbackEngine.ts`、`src/core/types.ts`（除非明确要改）。
3. **`useDoc` 用 `Object.is` 比快照**：selector 返回新数组会**无限重渲染**。
   要传 `isEqual`，或返回字符串/原始值。
4. **别用 `?.()` 调测试钩子**：会把"钩子不存在"静默吞掉，断言假绿。
   先 `typeof fn === 'function'` 断言存在，再读值。
5. **改 DOM 元素类型（span→input）要查读它的测试**：`textContent` / `.value` / `.checked`。
6. **E2E 先 build 再跑**：E2E 跑 `dist/`，不 rebuild 就是测上一版。
7. **E2E 只"等条件"不"等时间"**：固定 `sleep` 单跑够、全量连跑不够。

### 测试怎么写

- **Node 单测**：`*.test.mjs`，用 esbuild `buildSync` 把 TS 打包成 ESM 再 import。
  套路见 `tests/settings.test.mjs`（含假 localStorage mock）。
- **E2E**：`verify-*.mjs`，用 `tests/cdp.mjs` 的 `launchPage` + `createReport` + `report.check/summary`。
  `data-v` 属性是测试的定位锚点，命名要稳定。
- **CDP 合成鼠标做拖动会发 `pointercancel@0,0`**（第二次 mouseMoved 就取消）。
  拖拽类交互改用**页面内合成 `PointerEvent`**（见 `verify-caption.mjs` 的 ㉓ 段，有注释）。
  同时给拖拽容器加 `touch-action: none`。
