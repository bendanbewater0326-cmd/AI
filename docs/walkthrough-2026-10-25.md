## 2. 走查发现

### 产品级断点：0 个

### 观察项（轻微，不构成必改）

1. **导出文件名 = 工程名**：默认「未命名工程.mp4」。真实用户第一次导出大概率带着默认名存盘
   （之后在系统里改名）。可选优化：导出对话框顶部放可编辑文件名输入框（默认工程名）——
   归入 P1「导出预设体系」一并做（同一次 UI 改动）。

### 测试手法沉淀（进项目记忆，防复踩）

1. **未 focus 的元素 `.blur()` 是 no-op**（不派发事件，React onBlur 不触发）——淡入首跑
   "未生效"即此因。E2E 合成输入流：`focus() → 原生 setter 设值 → input → blur()`。
2. **waitFor 精确值有竞态**：异步导入可能让计数跳过目标值（assets 2→3 之间没有稳定的 2 态，
   音效先入使 2 提前满足）。多资产场景断言用 `>= n`。
