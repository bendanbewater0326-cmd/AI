# 手工体验清单（真实素材手感）

> **用途**：机器能验"对不对"（398 单测 + 42 个 E2E），验不了"顺不顺手"。
> 这份清单是给**人**用的：15 分钟走一遍，把别扭的地方记下来。
> **怎么用**：照着做，边做边在最后一张表里记。写完发给我（或者告诉我"看 docs 里那张表"）。
> **日期**：2026-10-21 · 版本：P2 全部交付后

---

## 0. 准备（2 分钟）

**不用打开任何外置浏览器。** 编辑器在客户端内置的预览面板里跑（我这边已经把 dev server 起好了）。

- 地址：`http://127.0.0.1:5173`
- 如果面板关了 / 白屏 / 服务停了：**跟我说一句"重启预览"**，我重新拉起，不用你敲命令。
- 想自己重启也行（在客户端终端里）：

```bat
cd /d "D:\项目专用文件夹\剪辑工具"
npm run dev
```

> Windows 的 cmd 里必须用 `cd /d` 加反斜杠：`cd "D:/..."` 不会切换盘符，
> 命令"看起来成功了"，但 `npm` 还在 `C:\Users\你` 下面找 `package.json`（报 ENOENT）。
> 提示符要变成 `D:\项目专用文件夹\剪辑工具>` 才算切过去。

**导入素材**：从资源管理器把视频**拖进左侧素材栏**，或点素材栏的导入按钮。
仓库里现成的素材（也可以拖你自己的）：

| 用途 | 路径 |
|---|---|
| 普通 720p（**带人声**，做粗剪/字幕用） | `tests/fixtures/hardline/sample-720p.mp4` |
| 1080p | `tests/fixtures/compat/plain-1080p.mp4` |
| 4K（**会转代理**，看性能） | `tests/fixtures/compat/uhd-4k.mp4` |
| 竖拍手机视频 | `tests/fixtures/compat/rotated-90.mp4` |
| 10 分钟长素材 | `tests/fixtures/compat/long-10min.mp4` |
| 无音频（屏幕录制类） | `tests/fixtures/compat/silent-720p.mp4` |

> **强烈建议**：至少混一段**你自己的真实素材**（比如微信里那个视频）。测试素材是合成的，
> 你的素材才会暴露真问题——上一轮"音频一直沙哑"就是这么找出来的。

> 内置面板里可能没有"另存为对话框"（File System Access 受限），这时素材栏会显示一条
> "内存模式"提示——**这是预期的**，导入、剪辑、导出都正常，只是刷新页面后素材要重新拖一次。

### 如果面板里拖不进文件 / 重新链接一直失败（内嵌面板的已知限制）

内嵌面板拿不到 File System Access 权限，`requestPermission` 一律 denied，**拖文件也可能被面板吞掉**。
这时用 **HTTP 喂文件**（不依赖任何浏览器权限）：

```bat
node scripts/serve-media.mjs --dir="D:/你的视频目录" --editor="http://127.0.0.1:5173/"
```

然后打开 `http://127.0.0.1:5300/` —— 每行一个视频，点「在编辑器中打开」即可（等价于
`?src=<文件URL>`，编辑器会自动导入）。支持 Range（拖动播放头不会卡）和 CORS。

### 先点一下顶栏「自检」（30 秒）

在动手之前先确认"这台机器 + 这个面板"的基本能力：点顶栏右侧的 **自检**，
会依次跑 6 项并显示 ✅/❌ 和具体数值：

| 项 | 看什么 |
|---|---|
| ① 运行环境 | WebCodecs 解码/编码是否可用、是否 secure context |
| ② 素材已导入 | 素材的分辨率 / 帧率 / 音频采样率与声道 |
| ③ 解码首帧 | 能不能解出第 0 帧 |
| ④ 预览出画 | 预览画面非黑像素数 |
| ⑤ 音频排期 | 播 0.6 秒，看排期块数与空洞数（gaps 必须是 0） |
| ⑥ 播放头 | 播放头帧号 |

**全绿再往下测**。有红的直接把面板「复制结果」发我——比描述现象准得多。
（自检只在开发构建里可用，生产构建会提示"需要在开发构建下运行"。）

## 3. 一句话 + 导出（5 分钟）

`Ctrl/Cmd + K` 唤起命令栏，`Esc` 关掉。逐条试：

| # | 输入 | 预期 |
|---|---|---|
| 3.1 | `去掉停顿` | 自动剪掉长静音，弹可撤销提示（素材里没停顿会提示"没找到超过 1 秒的停顿"） |
| 3.2 | `遮住左边` | 左半被遮住（露出背景），属性栏出现「蒙版」组可细调 |
| 3.3 | `对比更强` / `画面更亮` | 画面立刻变化，可撤销 |
| 3.4 | `加个降噪` | 属性栏出现降噪组；听感变化（有底噪的素材才明显） |

## 7. 别浪费时间的地方

这些**不用报**（已知边界或纯审美）：

- **自动字幕不出结果** → 没有语音识别通道（预期，见 3.6）
- **4K 实时播放卡** → 预览走代理，导出走原片；实时播放 4K 原片本来就卡
- **VFR 素材节奏轻微不准** → 已知：线性帧号映射假设 CFR，总时长对、内容有轻微拉伸
- **颜色/间距/字号/图标**这类纯视觉问题 → 我能自己看，占你的时间不值
- **拖到已有片段上会吸附/换轨** → 设计如此（不会重叠）
- **转场时长被夹到片段一半** → 设计如此（否则画面永远半透明）

## 8. 真出问题时的三件事

1. 先看**顶部红色错误条**，把文案**原样抄下来**（比"报错了"有用一百倍）
2. 打开控制台（F12）看有没有红字，截图或抄第一行
3. 记下**能不能重复**：再走一遍同样的步骤还会不会
