# 左栏「文本」面板实现方案

> 状态：**三步全部交付（2026-10-23）**。  
> 目标：把左栏第 3 个 Tab（文本）从「功能开发中」占位换成真正的文字模板库，  
> 交互对齐 opencut-classic：**顶部分类筛选 + 中部缩略图网格 + 点击/拖拽一键应用**。

## 交付记录（第 3 步）

「我的预设」复用 R-053：`capturePreset` 抓 `textStyle`、`buildPresetOps` 套用、存 settings。
面板只做筛选展示；我的预设主色描边 + 可删，系统预设灰边 + 不渲染删除按钮。
`PRESETS_CHANGED` 广播让属性栏与面板两份列表同步。

## 交付记录（第 2 步）

拖拽应用（独立 MIME `application/x-veditor-text`，ghost 落在文字轨、落点吸附）+
落轨全链路统一（`addText` / SRT 导入 / AI 转写全部走 `ensureTextTrackOps`）。

**顺带修掉一个真 bug**：`LayerPlacement.order` 直接用了 `track.order`，而它只在同类型内唯一，
文字轨 order=0 与 V1 的 order=0 撞号 → 文字被 V2 盖住（doc 里有字、预览像素不变）。
新增 `core/types.trackCompositeOrder()`（文字 `10000+order`）—— 合成顺序与屏幕顺序方向相反。

## 交付记录（第 1 步）

已落地：`core/textPresets.ts`（10 个模板 + 分类 + `presetToText`）、`ui/TextPanel.tsx`、
`TextContent.bold?/stroke?`（4 处归一化）、`core/placement.ensureTextTrackOps`、
属性栏「加粗 / 描边」开关、`tests/text-presets.test.mjs`（18 项）、
`tests/verify-text-panel.mjs`（22 项）。

**与本文原方案的一处重要偏差（实测发现）**：模板坐标原按 1080p 绝对值直接落片，
在 1280×720 工程下 `y=380` 会把「底部字幕」**推出画面**（预览纯黑、doc 字段全对）。
现已改成 `presetToText(preset, content, {width, height})` 按分辨率换算，
副作用是 4K 下偏移偏小的问题也一并解决。

## 0. 一句话结论 + 三个待你拍板的点

**结论**：文本面板可以做到"零底层改动"——现有的 `TextContent`（内容/字号/颜色/对齐/XY 偏移/底衬）  
已经够撑起 10 个视觉差异明显的预设。&#x4F46;**「花字」做不出来**（没有粗体、没有描边），  
这是唯一需要你决定的边界。

| # | 待定                                                 | 选项                                                | 我的建议                                                                                                                                                                                                                                        |
| - | -------------------------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A | 是否允许给 `TextContent` 加 **2 个可选字段**（`bold`、`stroke`） | ① 纯 UI，不加（花字只能用"底衬"近似）② 加 bold+stroke（约 40 行渲染改动） | **②**。这两个字段是**纯增量、缺省=现有行为**，不动任何既有逻辑；但没有粗体和描边，"主标题/花字"和"字幕"在缩略图里几乎分不开                                                                                                                                                                       |
| B | 新建文字落在哪条轨                                          | ① 保持现状：最上层**视频轨** ② 自动建/复用**文字轨**（T1）             | **②**，但要注意代价：文字现在挂在"当时最上层"的视频轨上，用户之后在它上面新建 V3，文字就被画面盖住。`TrackKind 'text'`、`nextTrackFor(doc,'text')`、`collectVisibleClips` 的"字幕轨也要参与合成"都是现成的，只是从没被用起来。**选②必须连 `buildSubtitleReplaceOps`（SRT 导入 / AI 转写）一起改**，否则会出现"手动加的字在 T1、导入的字幕在 V2"两套规则 |
| C | 默认时长                                               | ① 3 秒（现状）② 5 秒                                    | **①3 秒**，与现有 `addText()` 一致，不引入第二套默认值                                                                                                                                                                                                       |

> 下面按 **A=②、B=②、C=①** 写。若你选 A=①，第 2 章"能力边界"里标 ⚠️ 的 3 个预设换成纯底衬方案，其余不变。

## 1. 现状盘点（对着代码核过，不是猜的）

| 事实                                                                   | 出处                                  |
| -------------------------------------------------------------------- | ----------------------------------- |
| 文字不是"素材"，是挂在片段上的 `clip.text`                                         | `core/types.ts:259` `TextContent`   |
| 现有字段只有 7 个：`content / fontSize / color / align / x / y / background` | 同上                                  |
| `background` 是**半透明底衬**（按最长行测宽 + 圆角），不是矩形条                           | `render/textLayer.ts:74-87`         |
| 支持多行（`content.split('\n')`）、行高固定 1.28 倍字号                            | `textLayer.ts:64-65`                |
| 字号是**项目像素**（默认 72 @1080p），不是相对值                                      | `types.ts:1018`                     |
| `x / y` 是**相对画面中心**的像素偏移                                             | `types.ts:268`                      |
| 渲染结果按「尺寸+内容+7 个字段」缓存 8 张                                             | `textLayer.ts:25-27`                |
| 唯一写入通道是 `setClipText`（整份替换，天然可撤销）                                    | `types.ts:377`                      |
| 预设系统（R-053）**已经支持文字样式**：`payload.textStyle` 只存样式不存内容                 | `core/preset.ts:79-87, 241-248`     |
| 现有「添加文字」= 播放头处 3 秒、落在**最上层视频轨**                                      | `ui/TimelineView.tsx:827`           |
| 文字轨 `TrackKind 'text'` 已存在，但**从没被用来放文字**                             | `types.ts:162` / `placement.ts:128` |
| 拖拽协议已有自定义 MIME + 页面内变量两套机制                                           | `ui/dnd.ts`                         |

**结论**：数据层、撤销层、预设层、拖拽层全部就绪，缺的只是一个"模板库 UI + 应用规则"。

## 2. 能力边界（决定哪些预设能做、哪些做不了）

### 2.1 用现有字段就能做的

| 视觉              | 靠什么实现                     |
| --------------- | ------------------------- |
| 主标题 / 副标题 / 大标题 | `fontSize` + `y`          |
| 字幕条 / 白底黑字条     | `background`（底衬）+ `y` 贴底  |
| 角标 / 日期戳        | `align` + `x` + `y` + 小字号 |
| 多行（主标题+副标）      | `content` 里带 `\n`         |
| 任何配色            | `color`                   |

### 2.2 ⚠️ 做不了的（需要底层小扩展）

| 视觉          | 缺什么                                      | 加它的代价                                                                               |
| ----------- | ---------------------------------------- | ----------------------------------------------------------------------------------- |
| **花字（描边）**  | `TextContent` 没有 `stroke`                | `types.ts` +1 字段、`textLayer` 里 `strokeText` 一次、缓存 key +1 项、`normalizeClip` 归一化 +1 行 |
| **粗体标题**    | 字体串写死 `${fontSize}px "Microsoft YaHei"…` | 同上，`font` 串前面拼 `bold `                                                              |
| 阴影 / 发光     | 没有 `shadow`                              | `ctx.shadowBlur` 三行                                                                 |
| 入场动画（淡入/上滑） | 没有 `animationIn`                         | **不做**：要按"片段内偏移"算，属于渲染语义改动，风险高于收益                                                   |
| 自选字体        | 没有 `fontFamily`                          | **不做**：字体版权 + 跨机器缺字体，先在方案里明确排除                                                      |

> **A 选项要加的就是上表前两行**：`bold?: boolean` + `stroke?: { width: number; color: string } | null`。  
> 两个字段都**可选**，缺省等于现在的行为，老工程打开不会变样。

## 3. 数据模型：`src/core/textPresets.ts`（新，纯数据）

```ts
export type TextCategory = 'title' | 'caption' | 'label' | 'quote';

export interface TextPreset {
  id: string;                 // 'tpl-title-main'
  name: string;               // '主标题'（全中文）
  category: TextCategory;
  /** 点击时填进新片段的内容（含 \n 的多行模板） */
  content: string;
  /** 只覆盖样式，不含 content */
  style: Partial<Omit<TextContent, 'content'>>;
  /** 缩略图底色：深色预设用 dark，白底条用 light（否则白字在白底上看不见） */
  previewBg: 'dark' | 'light';
}

export const TEXT_CATEGORIES: ReadonlyArray<{ key: TextCategory | 'all'; label: string }> = [
  { key: 'all', label: '全部' },
  { key: 'title', label: '标题' },
  { key: 'caption', label: '字幕' },
  { key: 'label', label: '标注' },
  { key: 'quote', label: '金句' },
];

/** 预设 → 可直接落片的 TextContent（内容可被覆盖）。 */
export function presetToText(preset: TextPreset, content?: string): TextContent;
```

## 4. 交互规则（一条都不能含糊）

### 4.1 点击预设 —— 三种情况

```
选中了「文字片段」        → 套样式，**保留原文字内容**（一条 setClipText，撤销标签「套用文字样式」）
选中了「非文字片段」/没选 → 在播放头新建 3 秒文字片段（一条 addClip，撤销标签「添加文字」）
```

- 新建后**自动选中**该片段 → 右侧属性栏立刻显示文字控件，可以马上改内容。
- 套样式时如果预设内容多行、原内容是单行，**只换样式不换内容**（不把用户写的字冲掉）。

### 4.2 拖拽预设到时间线

- 新增 MIME `application/x-veditor-text`，`dnd.ts` 里照抄素材那套（自定义 MIME + 页面内变量，  
  **dragover 阶段读不到 getData**，必须靠模块变量提前知道要画多宽）。
- 落点 = 鼠标 x 换算的帧，走 `snapFrame` 吸附（与素材拖入同一套）。
- 落点 ghost 用文字片段的样子（宽度 = 3 秒 × zoom）。
- 落轨规则与点击一致：有文字轨 → 文字轨；没有 → 建一条；**不偷偷换到视频轨**。

### 4.3 分类筛选

- chips 横排，「全部」默认；点击只改本地筛选状态（不写 localStorage，避免"上次选了字幕、这次找不到主标题"）。
- 空分类（例如「我的预设」还没存过）→ 显示一句"还没有自定义预设，选中文字片段后在右侧「预设」里保存"，不显示空网格。

### 4.4 我的预设（第二期）

- 复用现有 `preset` 体系：`capturePreset(clip)` 已经会抓 `textStyle`；  
  `persist/presets.ts` 的 `loadPresets()` 直接读。
- 只在"当前选中的是文字片段"时展示，套用走 `buildPresetOps`（一个撤销步）。

## 5. 面板 UI

```
┌─ 文本 ──────────────────────────┐  ← 44px 图标条已在，这里是内容区（1440 下 309px）
│ 全部  标题  字幕  标注  金句      │  ← 分类 chips，横向可滚，高 24
├─────────────────────────────────┤
│ ┌──────────┐ ┌──────────┐       │
│ │  主标题   │ │  副标题   │       │  ← 缩略图网格：auto-fill minmax(120px,1fr)
│ └──────────┘ └──────────┘       │     16:9 卡片，点/拖
│ ┌──────────┐ ┌──────────┐       │
│ │  大标题   │ │ 主副标题  │       │
│ └──────────┘ └──────────┘       │
│  …                              │
├─────────────────────────────────┤
│ [＋ 添加文字]                    │  ← 底部固定：空白文字（不带预设）
└─────────────────────────────────┘
```

- **缩略图用 DOM 画，不用 canvas**：一个 16:9 的 div，字号按 `cardW / 1080` 等比缩放，  
  颜色/底衬/对齐直接映射成 CSS。理由：canvas 要维护第二套缓存与 DPR 处理，  
  而缩略图只是"看个大概"，DOM 版本还能被 E2E 用 DOM 断言。
- 卡片 hover：`border-color: accent` + 背景微亮（与素材卡一致，不加阴影）。
- 卡片 `draggable`，`cursor: grab`（与素材卡一致）。
- 无障碍：每个卡片是 `<button>`，`aria-label` = 预设名；chips 用 `aria-pressed`。

## 8. 验收标准（可执行）

**单测（`text-presets.test.mjs`）**

1. 10 个预设 id 唯一、名称全中文、分类合法；
2. 每个预设 `presetToText()` 出来的字段都落在合法范围（字号 12–240、颜色 `#rrggbb` 或 `rgba()`、y 在 ±540 内）；
3. `presetToText(p, '自定义')` 用传入内容覆盖模板；
4. 多行预设 `content` 含 `\n`；
5. （A=②）`bold`/`stroke` 缺省时 `createTextContent()` 的产物与现在**逐字段相等**（老工程不变样）。

**E2E（`verify-text-panel`）**

1. 点「文本」Tab → 10 张卡片可见，名称与顺序正确；
2. 点「标题」→ 只剩 4 张；点「全部」→ 10 张；
3. 没选中任何片段时点「主标题」→ 新增 1 个文字片段，`content='主标题'`、`fontSize=88`、落在**文字轨**；
4. 同上，按一次 Ctrl+Z → 片段消失（一步撤销）；
5. 选中已有文字片段（内容改成「我的字」）→ 点「底部字幕」→ **内容仍是「我的字」**，样式变了；
6. 选中一个**视频**片段 → 点预设 → 新增文字片段（不改视频片段）；
7. 拖「主标题」到时间线第 120 帧 → 新片段 `startFrame≈120`（±1 帧吸附）；
8. 拖到轨道头列 → 不新建；
9. 缩略图与套用结果一致：卡片里文字颜色 == 套用后 `clip.text.color`（DOM 断言）；
10. 面板在 15%（窄）和 40%（宽）两档下都不横向溢出；
11. 切换 Tab 再切回来，面板状态正常（不重复创建、不丢筛选）。

**回归**：全量 E2E 必须仍然全绿（当前 58 个）。

## 9. 风险与对策

| 风险                                    | 对策                                                                                                                                                                      |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `textLayer` 缓存 key 漏加新字段 → 改粗体/描边画面不变 | key 里显式拼上 `bold`/`stroke`，并加一条 E2E：改描边后读画布像素（**不能只断言 doc 字段**）                                                                                                          |
