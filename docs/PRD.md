## 1. 产品一句话定义

**一款嵌在 AI 客户端里的极简视频剪辑器：默认界面上看不见 AI，20 个高频操作做到极顺手，剩下的一切用一句话说完。**

客户端里生成或拖入的视频默认由它接管；需要 AI 时它才出现，说完就走。

### 已定案约束（不在本文重新讨论，仅作为输入）

| 项 | 定案 |
|---|---|
| 形态 | React + TypeScript Web 面板，可独立运行；预留 `?src=`、`postMessage`、Web Component 接入 |
| 预览 | WebCodecs 硬解 + Canvas 2D 合成 + rAF 帧调度 |
| 导出 | WebCodecs 编码 + mp4-muxer / gifenc；**MP4/H.264（含 AAC 音轨）、GIF、WAV、PNG 序列 四选一**；WebM 导出暂不提供（2026-10-20 决策，见 §11 Q9）；透明通道走 **PNG 序列 + ZIP**（R-062，2026-10-21 已交付） |
| 素材 | 只存 File System Access 文件句柄引用，不复制字节；不可用时降级内存模式并警告 |
| 工程 | 时间线 JSON 存 IndexedDB，自动保存 |
| AI | 宿主注入模型（用户零配置）；按语气判定建议/执行模式；变更产出结构化 `ClipOperation` |

## 2. 目标用户与核心场景

### 主要用户

**AI 客户端的内容创作者**：已在客户端里用 AI 生成素材（图生视频、口播、切片），想把它们拼成能直接发布的成片。会剪但不熟练，不想为剪 30 秒去装 Premiere。

**次要用户**：新手（把建议模式当老师）、需批量做尺寸适配的运营。

### 三个核心场景

**场景 A 生成后立刻拼片（主要场景）**
用户刚生成 4 段 5 秒视频，选中后点"剪辑"，剪辑器带素材打开。
> 作为一名内容创作者，我想在生成完成后不离开客户端就完成粗剪并导出，以便 10 分钟内把成片发出去。

**场景 B 用一句话做批量精修**
口播素材有大量停顿和口误。
> 作为一名口播作者，我想用一句话让 AI 去掉所有超过 1 秒的停顿，以便不用手动切 40 刀。

**场景 C 边问边学**
新手不知道什么时候该切。
> 作为一名剪辑新手，我想在选中片段时问"这里为什么要切"，以便边剪边学会判断。

## 3. 设计原则（可判定，不接受"体验流畅"式表述）

**P1. AI 隐形化**
默认态（未唤起 AI、未选中片段、无临时提示）截图中，AI 相关视觉元素 ≤ 1 个（仅顶栏右侧 `✦`），不允许出现任何 AI 文案（含"AI""智能""助手""推荐"）、聊天侧边栏、常驻浮窗、AI 按钮墙。
唤起后为**覆盖式浮层**，Esc 单次即消失并回到唤起前状态；消失后 DOM 不留可见 AI 元素。

**P2. 一屏之内、两层封顶**
1920×1080 下 P0 操作不需滚动即可达；点击深度 ≤ 2 层，无三级菜单。

**P3. 空态即动作**
任何面板无内容时不得留白，必须且仅呈现一个明确动作（如"＋ 导入媒体"），空态文字 ≤ 16 字。

**P4. 只显示此刻有用的**
右属性栏默认仅 4 项；未选中时 4 项灰显而非隐藏（避免面板跳动）；仅在选中片段具备相应能力时才展开分组。

**P5. 一个手势一件事**
同一元素只承担一种交互：拖内部 = 位移，拖左右 8px 边缘 = 裁剪，绝不混用，两者需 ≥ 8px 热区隔离。

**P6. 破坏必可逆**
任何改变时间线内容的操作必须进撤销栈（≥ 50 步）；不允许存在不可撤销的破坏性操作。

### AI 隐形化判定清单（验收时逐条截图核对）

| # | 判定项 | 通过标准 |
|---|---|---|
| 1 | 首次打开（空工程） | 全屏无 AI 文案，仅顶栏 1 个 `✦` |
| 2 | 剪辑中（选中片段） | 无 AI 建议气泡、无浮窗、无"AI 建议"角标 |
| 3 | 唤起后 | 命令栏从底部浮出**覆盖**时间线上沿，任何区块尺寸不变（像素级）；Esc 后完全还原，选中与播放头不变 |
| 4 | AI 执行完 | 只留一条可撤销 toast（≤ 4 秒），界面不留聊天记录 |

## 4. 需求池

规则：`must` 级全部可验收；括号内为里程碑；ID 唯一不复用。

### 4.1 P0 —— M1「能跑」+ M2「能剪」+ 一致性前提（R-001 ~ R-032）

**M1 「能跑」：R-001 ~ R-015**

| ID | 需求 | 验收标准 |
|---|---|---|
| R-001 | 工程初始化与参数跟随 | 空工程兜底 1920×1080 / 30fps；**导入第一个素材时，工程 fps 与分辨率自动改写为该素材参数，不弹窗、不需确认**；**只有第一个素材可改写工程参数**，之后导入参数不同的素材一律走 R-031 映射；顶栏显示项目名，可双击重命名并持久化 |
| R-002 | 导入媒体 | 支持拖拽入窗与 `＋ 导入媒体`；**支持 mp4/mov/webm**（webm 于 2026-10-21 由 T19 放开，见 §11 Q9 的推翻说明；帧精确承诺与 mp4 一致，**不分级**）；其它容器显式拒绝并给可读提示；导入后 3 秒内出现条目 |
| R-003 | 真实缩略图 | 素材库缩略图取自素材首帧解码结果，非纯色占位；同一素材重复导入不产生重复条目 |
| R-004 | 句柄引用 | 以文件句柄引用保存，不复制字节；句柄不可用时降级内存模式并常驻警告条"关闭页面工程会丢失" |
| R-005 | 素材上时间线 | 拖素材到时间线或双击素材，生成 V1 片段，入点 0、时长 = 素材时长 |
| R-006 | 播放/暂停 | 空格切换；连续播放 10 秒内音画不同步 ≤ 1 帧 |
| R-007 | 逐帧步进 | `←`/`→` 每次 ±1 帧；按住 Shift 每次 ±10 帧；到首尾帧停止不回绕 |
| R-008 | 播放头 seek | 点击/拖动时间标尺、拖动播放头均可 seek；**seek 停止后预览画面帧号 == 目标帧号**（误差 0 帧）。帧精确承诺覆盖 R-002 全部已支持格式，**不按格式分级**——做不到的格式不得宣称支持导入 |
| R-009 | 时间码 | 显示格式 `HH:MM:SS:FF`，FF 进制 = 项目帧率；总时长与当前帧同时可见 |
| R-010 | 时间标尺 | 刻度随缩放自适应（帧/秒/分三级），缩放后不重叠、不缺标签 |
| R-011 | 播放头 | 与当前帧严格同步，播放时自动跟随（超出可视区才滚动，步长 ≥ 1 屏宽） |
| R-012 | 片段块渲染 | 时间线渲染片段块，块内展示首帧缩略图 + 素材名；块宽度与片段时长按同一比例换算 |
| R-013 | 自动保存 | 工程变更后 1 秒内写入 IndexedDB；刷新页面后素材、轨道、片段、播放头位置全部恢复 |
| R-014 | 空态 | 素材栏空 → 仅"＋ 导入媒体"；时间线空 → 居中一行提示"把素材拖到时间线上"；无选中 → 属性栏 4 项灰显 |
| R-015 | 项目参数入口 | 顶栏显示"1920×1080 · 30fps"，可手动修改；**无片段时改动立即生效不确认**；**已有片段时须二次确认**，弹窗事先给出「受影响片段数 + 最大位移帧数」；重排按绝对时间等比、素材跨度不变、相邻贴紧、不做级联推移、整批 1 个撤销步（细则见 `spec:§7`） |

**M2 「能剪」：R-016 ~ R-030**

| ID | 需求 | 验收标准 |
|---|---|---|
| R-016 | 切分 | 在播放头处切分选中片段（未选中则切分播放头下所有片段）；两侧帧数之和 = 原帧数、无丢帧（**同帧率 0 容差；混合帧率 ±1 帧，素材跨度守恒必须 0 容差，见 `spec:§6`**）；±1 是两侧独立 half-up 取整的**必然结果**（约 11.6% 切点会偏），非精度缺陷、不可消除，除非放弃"时长独立取整"；切点在首/末帧时不产生操作、不入栈 |
| R-017 | 删除片段 | `Delete`/`Backspace` 删除选中片段，原位留空；删除后播放头位置不变 |
| R-018 | 波纹删除 | `Shift+Delete` 删除并把同轨后续片段整体前移，前移量 = 被删片段时长；其他轨不受影响 |
| R-019 | 片段水平拖动 | 拖动片段改起始帧，落点吸附后起始帧为整数帧；不允许与同轨已有片段重叠（重叠则落到最近合法位置） |
| R-020 | 片段跨轨拖动 | 可拖到另一条同类型轨道（V1↔V2）；拖到不兼容轨道时显示禁止光标并回弹 |
| R-021 | 首尾裁剪 | 拖左边缘改入点、右边缘改出点；不得超素材边界；最短 1 帧 |
| R-022 | 吸附 | 拖动/裁剪时吸附到片段边缘、播放头、时间线零点，吸附阈值 8px，命中时显示竖向吸附线；按住 `Alt` 临时禁用吸附 |
| R-023 | 多轨结构 | 默认 V2/V1/A1；可新增视频/音频轨；轨道头可重命名；V2 覆盖 V1 |
| R-024 | 音频播放 | A1 音频随播放输出；任一轨静音（M）后不出声，画面不受影响 |
| R-025 | 撤销/重做 | 至少 50 步；须覆盖切分/删除/波纹删除/拖动/跨轨/裁剪/属性/加轨；重做栈在新操作后清空 |
| R-026 | 快捷键全集 | 第 6 节 P0 快捷键全部生效；输入框聚焦时除 Esc 外不触发快捷键 |
| R-027 | 单选与联动 | 点击片段单选并高亮（2px 描边）；选中片段后属性栏 4 项可编辑，值反映该片段真实状态 |
| R-028 | 属性编辑 | 缩放（0–500%）、位置 X/Y、不透明度（0–100%）、混合模式（正常/叠加/滤色/正片叠底）；改值实时反映到预览 |
| R-029 | 时间线缩放 | `Ctrl/Cmd+=/-` 或 `Ctrl/Cmd+滚轮`；以播放头为锚；范围 1–20 px/帧 |
| R-030 | 时间码跳转 | 点击时间码可输入目标时间码，回车跳转；非法输入回退到原值并保持焦点 |

**M1 一致性前提（编号追加在 P0 末尾，逻辑属 M1 验收前置）：R-031 ~ R-032**

| ID | 需求 | 验收标准 |
|---|---|---|
| R-031 | 混合帧率映射 | 素材 fps ≠ 项目 fps 时按统一规则换算：片段时长 `round-half-up`，帧映射 `hold-previous`（永不取未来帧），不插帧；**完整公式、边界与 10 个必测用例见 `spec:T1–T10`**；预览、导出、缩略图、seek 共用同一实现。验收：24fps×10s 进 30fps 工程后片段 == 300 帧；预览第 N 帧与导出编码前第 N 帧 RGBA 逐像素通道差最大 ≤ 2；解码后同帧 PSNR ≥ 35dB |
| R-032 | 混合采样率 | 项目音频时基固定 48kHz；异采样率素材统一重采样后再混音，不做时长拉伸补偿。验收：A1 播 60s 后音画偏差 ≤ 1 帧；导出音频与视频总时长差 ≤ 1 帧；44.1k 与 48k 混排时两段时长误差各 ≤ 1 帧 |

| R-044 | AI 命令栏 | `Ctrl/Cmd+K` 唤起，底部浮出覆盖时间线；支持自然语言输入与 Esc 关闭；关闭后布局像素级还原 |
| R-045 | 语气判定与建议呈现 | 提问式（含"为什么/怎么/建议/能不能"）→ **建议模式**：命令栏输出文字建议，**同时在时间线对应帧渲染 1px 虚线「建议切点」标记**；标记不改变任何片段数据、不入撤销栈，旁挂极小「采纳」（点击才执行，执行后才入栈）；再次唤起 / 点空白 / Esc 即消失，默认态不存在于 DOM。命令式（动词开头）→ **执行模式**：直接改时间线 |
| R-046 | 变更结构化与反馈 | 所有 AI 变更产出 `ClipOperation` 数组并入撤销栈，一次 AI 操作 = 一个撤销步；toast 必须含可读操作描述（如"已剪掉前 3 秒"），停留 4 秒且可点撤销 |
| R-047 | 模型注入 | 模型由宿主注入，用户界面无任何 API Key 输入项、无模型配置页 |
| R-048 | AI 不可用降级 | 无可用模型时 `✦` 置灰不可点，hover 提示"当前客户端未提供模型"；核心剪辑功能完全不受影响 |
| R-049 | 纯音频导出 | 从时间线提取音频为 M4A 或 WAV，时长与区间一致（误差 ≤ 1 帧，采样率 48kHz） |
| R-050 | 三种接入 | ✅ **2026-10-21 全部交付**：`?src=` 预加载素材；`postMessage` 四条命令（`setProject` / `getProject` / `importAsset` / `export`，一请求一响应、`id` 原样回传、导出字节以 `ArrayBuffer` transfer 回传）；`<veditor-panel>` 可挂载。协议与错误码见 `docs/PROJECT-STATUS.md` §7.2 |
| R-051 | 长尾 AI 通道 | 曲线调色、精细蒙版、多机位、色彩管理四类能力仅通过 AI 命令栏触发，不提供 UI 控件 |

| R-056 | AI 蒙版跟踪 | ⚠️ **2026-10-21 部分交付**：自然语言方位词（左/右/上/下/中间）→ 矩形/椭圆蒙版 + 羽化 + 反向（**动词决定方向**：遮住=挖掉、只露=保留），属性栏可细调形状/位置/尺寸/羽化/反向，跨帧变化靠**关键帧插值**（手动跟踪），`setClipEffect` 可撤销。**自动跟踪（视觉模型逐帧找目标）未做** |
| R-057 | AI 多机位 | ⚠️ **2026-10-21 部分交付**：把 N 条视频轨当机位，在切换点切分 + 逐段只开一个机位（渲染零改动、一次撤销）；规则两档——"每 N 秒"轮流切、"跟说话人"按**每个机位的音频能量**选。**说话人识别未做**——一人一麦的访谈可用，共享房间麦会退化成"谁离麦近切谁" |
| R-058 | AI 色彩管理 | ⚠️ **2026-10-21 部分交付**：`.cube`（3D LUT）导入 + 强度混合，走 GPU 三线性插值，随工程保存；**色彩空间转换（sRGB↔P3 等）未做**——需要矩阵 + 传递函数，是另一件事 |
| R-059 | AI 自动字幕 | ⚠️ **2026-10-21 部分交付（通道已打通）**：① SRT 导入（容错解析）→ 每个 cue 一个文本片段、**整段替换**旧字幕（一个撤销步）、导出 SRT；② **语音识别通道**：一句话「自动生成字幕」→ 客户端抽音频（混音→下混→16k）→ 宿主 `AIModelPort.transcribe()` → 清洗时间戳/重叠/空文本 → 落到字幕轨。**客户端不做 ASR 本身**——纯前端没有可用的本地识别模型，宿主不实现 `transcribe` 时命令栏给可读拒绝（不产出空字幕） |
| R-060 | AI 智能粗剪 | ✅ **2026-10-21 交付**。"去掉静音/停顿/口误"一次成片，结果作为单次可撤销操作（实测：8s 素材剪掉中间 2s，1 段变 2 段，一次 Ctrl+Z 还原） |
| R-061 | AI 音频降噪 | ✅ **2026-10-21 交付**。自然语言触发（降噪/去噪/底噪/人声增强）→ 片段级 `denoise` 效果（噪声门 −70..−20dB + 增强 0..100%），非破坏性、可撤销、原音频随时可恢复；预览与导出同一套 DSP |
| R-062 | 透明通道导出（降级方案） | ✅ **2026-10-21 交付**。产物为 **RGBA PNG 序列 + ZIP**，帧精确、无损、保留 alpha；`frame_000001.png` 起连续编号，附 `frames.json` 记帧率与起止帧；**明确不产出可直接播放的透明视频**（编码器不开放 alpha，见第 9 节） |
| R-063 | 触屏适配 | ✅ **2026-10-21 交付**。≤1024px 收窄左右栏、可点区域 ≥26px、不隐藏任何 P0 控件；实测 820×1180 下加文本/触摸拖播放头/导出均可用 |
| R-064 | 无障碍强化 | ✅ **2026-10-21 交付**。`aria-live` 播报「播放头时间码 + 选中片段」（400ms 节流）；高对比主题（`data-theme=contrast`，只改颜色不改布局，选择持久化） |

## 8. 数据模型草案（供架构师参考，非代码）

**Project**
`id` · `name` · `fps` · `width` · `height` · `sampleRate`(固定 48000) · `durationFrames` · `frameMapPolicy`(固定 `holdPrevious`) · `durationRounding`(固定 `halfUp`) · `tracks[]` · `assets[]` · `playheadFrame` · `zoomLevel` · `schemaVersion` · `createdAt` · `updatedAt`

**Asset**
`id` · `name` · `kind`(video/audio/image) · `handleRef` · `sourceMode`(fs/memory) · `status`(ok/offline/memory) · `fps`(素材自身帧率) · `durationFrames`(**素材时基**整数帧) · `durationSec`(仅用于校验) · `sampleRate` · `channels` · `width` · `height` · `hasAudio` · `thumbnailRef`

**Track**
`id` · `kind`(video/audio) · `name` · `order`(0 起，越大越靠上) · `locked` · `muted` · `hidden` · `clips[]`

**Clip**
`id` · `assetId` · `trackId` · `startFrame`(**项目时基**) · `inFrame`/`outFrame`(**素材时基**) · `speed` · `enabled` · `transform{scale, x, y, opacity, blendMode}` · `audio{gain, fadeInFrames, fadeOutFrames}` · `effects[]` · `transitionIn?` · `transitionOut?`

**Effect**
`id` · `clipId` · `type` · `params{}` · `keyframes[]` · `enabled` · `order` · `source`(ui/ai)

**Keyframe**
`frame`(相对片段入点) · `property` · `value` · `easing`

**ClipOperation**（AI 与 UI 共用的变更单元，撤销栈与 AI 输出的唯一载体）
`id` · `opType`(split/delete/rippleDelete/move/trim/setProperty/addEffect/removeEffect/addTrack/...) · `targetClipIds[]` · `payload{}` · `inverse{}` · `source`(ui/ai) · `timestamp`

**UndoEntry**
`id` · `label`(UI 或 AI 生成的可读描述) · `operations[]` · `createdAt`

> **关键约定（必须由架构师写入实现约束）**
> 1. 所有时间字段用**整数帧**，禁止数据层出现秒或浮点；换算只在渲染与显示层发生。
> 2. 两套时基严格分离：`startFrame` 属**项目帧栅格**，`inFrame/outFrame` 属**素材帧栅格**，两者只通过 R-031 的映射换算（完整公式、边界与用例见 `spec:T1–T10`），禁止在任意代码位置各自取整。
> 3. 映射函数必须**单一实现**，预览层与导出层调用同一函数，不允许另写一份"差不多"的换算。
> 4. 音频统一在混音前重采样到项目 `sampleRate`(48kHz)，`speed` 与重采样互不影响；导出音频总时长以项目帧栅格为准反推。
> 5. 只允许"项目帧→素材帧"单向推导，反向禁用。

## 9. 非功能需求

**性能**

| 指标 | 目标 |
|---|---|
| 预览帧率 · 4K 单轨 | ≥ 30fps |
| 预览帧率 · 1080p 双轨叠化 | ≥ 59fps |
| seek 响应 · 回退 ≤ 15 帧 | ≤ 100ms |
| seek 响应 · 回退 > 15 帧 | ≤ 800ms，期间必须显示"定位中"态 |
| seek 正确性 | **不因性能分档妥协**：松手后显示的必须是目标帧，误差 0 帧 |
| 切分/删除/拖动 UI 反馈 | ≤ 16ms 内可见（乐观更新，不等落盘） |
| 导入到可预览（100MB / 1080p） | ≤ 3s |
| 撤销栈 | 50 步，占用 ≤ 50MB |
| 长任务 | > 50ms 不阻塞主线程（导出/导入/缩略图） |

**兼容性**

- Chromium 111+：全功能（WebCodecs 硬解、File System Access、MP4/H.264、WebM/VP9 **导入**、GIF 导出）。
  PNG 序列导出（R-062）已交付：产物是 ZIP，不是可播放视频（编码器不开放 alpha）。
- Safari 17+：降级路径 —— 无 File System Access → 内存模式 + 常驻警告；解码走 `<video>` element 兜底（`exactSeek=false`）。
  **导出能力未验证**：原计划"导出走 WebM"，但本项目不提供 WebM 导出通道（见 Q9 变更记录），Safari 下导出待补。
- Firefox：仅可只读浏览工程，剪辑与导出置灰并提示"建议 Chrome/Edge"。
- 窗口 1280×720 起可用；最小宽度下左右栏自动折叠。

> **透明通道限制（全平台）**：WebCodecs 编码器不开放 alpha 路径（实测见 `docs/tech-preflight.md`），任何浏览器都不承诺可播放的透明视频（R-062）。

**无障碍**

- 全部 P0 操作可纯键盘完成；焦点顺序：顶栏→素材栏→预览→属性栏→时间线。
- 焦点环始终可见（2px）、文字对比度 ≥ 4.5:1（含灰字），状态不单靠颜色传达。
- 尊重 `prefers-reduced-motion`；片段与播放头变化用 `aria-live=polite` 播报（节流 ≥ 500ms）。

**隐私与安全**

- 素材字节不离开本机。
- AI 请求仅携带：指令文本 + 必要元数据（帧率/时长/轨道结构）+ 至多 1 张低分辨率预览帧，不上传原始素材。
- 每次 AI 请求前，浮层内以一行小字说明将发送什么（不弹窗）。
