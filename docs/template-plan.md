# 工程模板方案（已交付，2026-10-25：T1 数据层 + T2 入口 + T3 测试）

> 摸底日期：2026-10-25。定位（用户拍板）：轻量创作辅助——纯配置（文字样式 + 系统特效 +
> 转场），零素材依赖、零新增能力、入口在文本面板顶部、单个撤销步。
> 硬边界：不动 `core/types`、渲染、导出；全部复用现有构建器。

---

## 1. 摸底：语义定型（本方案最重要的决策）

**特效/转场必须挂在视频片段上**——模板自身无素材，所以模板不是"凭空生成工程"，
而是**「编排方案」作用于当前工程**：

| 工程状态 | 套用行为 |
|---|---|
| 有视频片段 | 完整套用：给**第一个视频片段**挂特效/转场 + 落文字（开场类）或给**最后一个**挂（结尾类） |
| 只有文字/空工程 | 降级：只落文字部分 + 可读提示"导入素材后可再套一次，特效转场会自动应用" |

这个语义同时满足"零素材依赖"（模板文件纯配置）与"生成带文字特效转场的结构"
（配合用户已导入的素材）。**追加而非替换**：模板在当前工程上叠加，不清空用户内容。

## 2. 现有构建器（全部直接复用，零新规则）

| 需求 | 复用件 |
|---|---|
| 落文字（建轨+落片同批） | `core/textClip.buildNewTextOps`（文本面板/AI 文案/右键共用） |
| 文字样式 | `core/textPresets.presetToText`（按工程分辨率换算坐标——模板写 1080p 参考值即可） |
| 特效 | `core/effectTarget.buildEffectOps(clip, preset)`（id 复用/等值跳过/替换单例） |
| 转场 | `core/transitionTarget.buildTransitionOps(clip, side, next)` + 时长夹取 |
| 一次提交 | ops 数组一次 `store.dispatch(ops, label, 'ui')` = 单个撤销步（AI addTextClip/性能造段同款先例） |

## 3. 模板清单（4 套，全中文）

| 模板 | 内容 |
|---|---|
| **Vlog 开场** | 主标题「这里是……」+ 副标题（居中下移）+ 首段视频淡入转场 + 提亮特效 |
| **知识科普片头** | 顶部章节标题 + 高对比特效 + 首段淡入 |
| **短视频结尾** | 居中「关注在看」行动号召文字 + 尾段淡出转场 + 暖阳特效 |
| **好物展示** | 底部字幕条「好物名称/一句话卖点」+ 柔和特效 + 首段淡入 |

每套 = `{ 文字片段数组（相对工程起点的帧位 + 样式预设引用），特效预设 id，转场 {presetId, side} }`
——纯数据（`core/projectTemplates.ts`，静态常量，非 JSON 资源）。
