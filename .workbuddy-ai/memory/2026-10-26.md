### ⚠️ 一处设计被我写错、被工程师用实测推翻

方案 §2 我写的是：「外层 `pointer-events: auto` + spotlight `none`，
靠'目标不在容器子树里、事件不冒泡到容器'来防误关」。

**这条在浏览器里不成立** —— 我漏了**命中测试只看几何、不看背景透明度**：
`inset: 0` + `auto` 就是一块吃满全屏的透明板，`elementFromPoint` 会返回它自己，
底下的「导入」按钮、时间轴**一个都点不到**。

工程师的取证：`elementFromPoint(素材图标中心) → 返回 .v-onboarding`。

修正后的三层：
```
.v-onboarding            pointer-events: none   ← 外层不吃点击
.v-onboarding__spotlight none                   ← 洞能穿透
.v-onboarding__tip       auto                   ← 只有提示框可点
「点空白关闭」改由 window pointerdown 捕获阶段判：
   命中 tip / 当前步目标 / 可交互控件 → 不关
   其余 → onClose('skipped')
```

教训已写进 CSS 注释（`app.css` 的 `.v-onboarding` 段）与 E2E（穿透那条断言）。

### 顺带修 verify-caption ㉑b 的容差

全量 76 个 E2E 里唯一红的就是它。工程师给了完整证据链（引导没渲染 / 3 个并发 E2E 可复现同一数值 /
空闲单跑 5 次全绿 / 数值在 356/292 与 373/275 之间漂移）。

根因：列表可视高度会被全局 UI（错误条 / BusyBar）临时压矮十几像素，
`scrollIntoView({block:'center'})` 之后再断言就会漂移（实测距顶 292px / 列表高 ~280 = 整行在框外）。

**修法**：容差从 1px 放宽到一整行高 26px；`scrollTop > 0` 那条仍守着"确实滚过"。
（改的时候我自己踩了一次坑：把含反引号的注释写进了模板字符串，提前结束字符串 → 语法错。
已改为放在模板外。）

### P1 GIF 导出预设（提交 `7973030`）

| 档 | 宽度 | 帧率 |
|---|---|---|
| 高清动图 | 720 | 20 |
| 竖屏动图 | 360 | 15 |
| 表情包 | 240 | 10 |
| 自定义 | 状态指示（disabled）| 手动改输入框即进入 |

**摸底纠正了一个假设**：GIF **没有"画质"参数** —— `exporter.ts:355` 是
`quantize(image.data, 256, { format: 'rgb565' })`，256 色写死。所以档位只靠分辨率 + 帧率区分，
**不做假的"画质"滑杆**。

**MP4 预设与 GIF 预设不是同一套逻辑**（这点容易误会成"技术路径一致"）：

| | MP4 预设 | GIF 预设 |
|---|---|---|
| 改什么 | 工程参数（`doc.w/h/fpsMilli`）| 导出选项（`gifWidth`/`gifFps` 两个面板内 state）|
| 副作用 | 有片段时重算所有片段时间 → **必须 confirm** | 零副作用 → **不弹确认** |

用 **`docVersion()` 守住零副作用**（切 GIF 预设后版本号 6→6）——
比"读宽高没变"更本质：后者只证明三个字段没动，前者证明**整份 doc 一个字节都没改**。

**两个必须补的细节**：
1. `select` 里原本只有 480/720/1080 和 10/15/24 —— 预设设 360/240/20 时**会显示空白**
   （值进了 state 但选项不存在）。已补 240/360/720 与 20fps。
2. 高度不传，`targetHeight = doc.height * (targetWidth / doc.width)` ——
   所以"竖屏动图"在竖屏工程下自然 360×640，横屏下 360×203，**一个预设两种工程都对**。

**高亮由 width+fps 反查**（`activeGifPreset`），不另存 `selectedPreset` —— 避免两份状态不同步。
手动改输入框 → 反查落空 → 自动显示「自定义」（E2E ⑤ 守住）。

CSS 一行没加（全复用 MP4 的 `v-export__presets` / `v-export__preset`），`main.css` 60.6KB 未变。
