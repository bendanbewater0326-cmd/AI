## S1.4 落地：时间线高度 50%（15%–70% 可拖）

用户要求：默认 50%、可拖 15%–70%、复用分隔条组件（热区与左右栏一致）、
localStorage 记住高度、**只动布局层**（渲染/素材/业务逻辑零改动）。

### 关键决定：百分比只存在"无单位变量"里

```css
--v-timeline-pct: 50;                                                   /* 唯一真相 */
--v-timeline-h: calc((100vh - var(--v-topbar-h)) * var(--v-timeline-pct) / 100);
```

`--v-timeline-h` 有三类消费者：grid 行高、预览 16:9 的宽度计算、命令栏/toast 的 `bottom`。
后两者要求它是**长度**。若把它直接定义成 `50%`，`calc(100vh - … - 50%)` 里的 50% 会按
**宽度**解析（属性语境决定百分比基准）→ 预览尺寸静默算错，不报错、只是"看起来小一点"。

### splitter 抽成三面板共用

`PANELS` 表描述每个面板：轴（x/y）、变量名、单位（`%` / 空）、存储键、方向 sign、min/max。
时间线：y 轴、`sign = -1`（往上拖变大）、范围 15–70、**无折叠按钮**
（高度归零后没有任何替代入口）。热区仍 4px；拖拽时 body 加 `v-splitter-dragging--y`
→ `row-resize`。

### 顺手删的死代码

`TimelineView` 里 `.v-timeline__splitter` 是个 `aria-hidden` 的空 div，**从未接过事件**
（`ui-refactor-plan` 里写的"已经能拖"是假设，实际没有）。改成 `.v-workspace` 第 2 行的
真分隔条，三行全部显式 `grid-row`（S1.2 的同一课：别依赖自动放置）。
`.v-stage__screen` 的宽度 calc、`.v-cmdbar` / `.v-toast` 的 `bottom` 都补了 `--v-splitter-h`。

### 两个坑

1. **`calc()` 之后不能拿 `getPropertyValue` 做数值断言**：`uiLayout().vars.timelineH`
   读出来是 `calc((100vh - 48px) * 50 / 100)` 这串 token，不是 `380px`。
   测试一律读元素 rect（`uiLayout().timeline.h`）。
2. 15% 时时间线只有 109px（工具栏 28 + 标尺 24 = 52，剩 57 < 一条 60px 视频轨），
   轨道区靠 `.v-tl-scroll` 滚动 —— 预期行为，不是裁切。

## 转场面板摸底（`docs/transition-panel-plan.md`，待确认）

### 核对出的关键事实
- 转场只有 3 种（crossDissolve / fadeIn / fadeOut），挂在**片段**的
  `transitionIn` / `transitionOut` 上，不是独立实体。
- `transitionIn` 的窗口**以接缝为中心** `[start-D/2, start+D/2)`；crossDissolve 会把
  **左侧严格紧邻**（`endOf(prev) === start`）的片段拉进来反向淡出；fadeIn 不需要左邻。
- `transitionOut` **只处理 fadeOut**；`transitionOut.crossDissolve` 被**静默忽略**
  （属性栏把 crossDissolve 永远写成 in 侧，所以只有手改工程才会出现）。
- 不吃两侧内容：边界外用**冻结帧**补（A 冻末帧 / B 冻首帧）。
- 时长上限 = `floor(片段时长/2)`；属性栏夹 0.1–2 秒再夹上限；默认 0.5 秒。
- 导出与预览共用 `engine.renderFrame` → 转场天然导出兼容。
- 时间线只画**固定 12px 楔形**，不随真实时长变化。
- **没有音频交叉淡化**（只有画面 opacity）。

### 方案要点（待拍板 A–E）
A 继续挂片段侧；B 叠化缺左邻→提示不降级；C 时长三档 0.3/0.5/1.0；
D 音频淡化不做；E 不补新类型（`TransitionOverride` 只有 opacity+frozenFrame，
滑入/擦除要扩渲染模型）。分两步：①面板+点击 ②拖拽+接缝吸附+ghost。
新增 `core/transitionPresets.ts` + `core/transitionTarget.ts`（纯函数，可 Node 穷举边界）。

- `snapToSeam(track, frame, ±12px/zoom)`：**不吸附会出错** —— 鼠标在接缝左 4px 时
  `clipAtFrame` 命中左段，而左段没有左邻 → 叠化直接判不可用。实测吸附后左 4px 也能落对。
- `ephemeral.transitionGhost`（与 `dropGhost` 分开：转场没有自己的时间跨度）+
  `drawTransitionGhost`：加宽楔形 + 接缝竖线，绿/红。**不可落也要画**（红），
  否则用户不知道为什么没反应。
- 角标宽度从固定 12px 改成 `min(片段宽, max(3, D/2×zoom))`（入场只算片段内那一半）。
- 删掉 `TRANSITION_MARK_WIDTH` 常量。

### 测试里踩的坑（重要）
量角标宽度第一版"数紫色像素"，两档都是满格 159px ——
**视频片段底色本身就是淡紫 `--v-clip: #d9d7f0`**，楔形只是同色系加深，按颜色筛会把整块算进去。
改成"两次渲染逐点做差、看差异延伸到多远"（实测 47px），与底色无关。

## 特效面板摸底（2026-10-23）

方案：`docs/effect-panel-plan.md`（待用户拍板 A–F）。

**能力底数（硬事实）**：渲染层只认 4 个画面效果 —— `colorGrade`（4 参数 -100..100）、
`curve`（只有 2 控制点）、`lut`（要外部 .cube）、`mask`（空间操作），加 1 个音频 `denoise`。
**没有**模糊/像素化/光效/故障/锐化/暗角。合成顺序硬编码 `transform → grade → curve → LUT → mask`，
`Effect.order` 是**死字段**（全仓库无人读）。加第 5 种要改 `Compositor` 接口（WebGL + Canvas2D 两套）。
导出走 `exporter.ts:167` 的 `compositor.captureFrame()`，与预览同一张离屏缓冲 → 已有特效天然一致。

**结论**：能一键套用的只有 `colorGrade`。面板 = 14 个调色预设 / 4 分类。

**两个关键坑**：
1. `setClipEffect` 是**同类型单例**（先 filter 掉同类型再加）→ 应用第二个是替换不是叠加，
   UI 必须让这件事可见，否则用户以为叠了两个滤镜。
2. 缩略图**不能用 CSS `filter: brightness()`**：CSS 是乘法，着色器是 `c += b/200` 加法
   （contrast 也是围绕 0.5 重算）。照抄 CSS 会让缩略图与预览不一致。
   正确做法：素材 IDB 缩略图 → 80×45 离屏 canvas → 逐像素复算 `GRADE_GLSL`。
   *顺带发现*：Canvas2D 降级路径（`compositor.ts:1245`）用的正是 `ctx.filter`，
   所以无 WebGL2 时调色与 WebGL 略有差异 —— 既有实现，本轮不动。

**另一条**：属性栏的调色/曲线整块被 `!isText` 包着 → **文字片段加得上、去不掉**。
本轮直接拒绝"拖到文字片段"，不做半成品。

## 特效面板第一步（2026-10-23）

`core/effectPresets.ts`（14 预设 / 4 分类）+ `core/effectTarget.ts`（落点/单例/操作构造）
+ `render/grade.ts`（`GRADE_GLSL` 的 JS 逐字版）+ `ui/EffectPanel.tsx`。

**三条规则**：
1. `setClipEffect` 是同类型单例 → 换预设是**替换**；`buildEffectOps` 在"参数已相同"时返回空数组
   （不占撤销步）。
2. 「原片」= **删 effect**，不是写四个 0（后者在 effects 里留一条空记录，属性栏显示空调色）。
3. 原片卡在**任何分类下都排第一**（切到「风格」也能一键取消特效）。

**踩到的一个真问题**：`thumbnailRef` 导入时同步填好，但缩略图 blob 是 `putThumbnail`
**异步**写进 IDB 的。面板常驻挂载 → 很可能在落库前读一次 → 读不到就**永久**停在兜底图
（`sourceAssetId` 不再变，effect 不重跑）。修法：读不到重试 5 次 × 400ms。
E2E 用 ⑩b「原片卡色差 5.4（兜底图约 12）」把这条钉住。

**顺手消掉的重复**：`gradeOf` 从 `media/playbackEngine` 搬到 `core/effectTarget.currentGrade`，
playbackEngine 改成一行委托（面板要读同一份来判断"这个预设是不是已经应用过"）。

**数字**：单测 639/38；E2E 61 个（`verify-effect-panel` 16 项）；构建 673.0KB（+9.2KB）。
